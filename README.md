# 旋转迷宫 · Rotate Maze

基于相邻 `ball-maze/index.html` 的独立版本。双击 `index.html` 即可游玩，无依赖、无需联网或传感器权限。

## 操作

- 键盘：← / A 逆时针旋转，→ / D 顺时针旋转；按住 Shift 慢转。
- 手机 / 鼠标：按住底部 ↶ / ↷ 按钮；也可以在画布上围绕地图中心拖动。
- 松开停止旋转，小球继续受重力滚动。普通旋转速度 120°/秒，Shift 慢转 30°/秒，可连续转过多圈。
- 空格或顶部 Ⅱ 暂停；切后台或窗口失焦自动暂停。
- 重玩或进入新关时地图回到 0°；掉洞在检查点复活，保留当前地图角度和已收集星星。

## 保留内容

原版 50 关、十大主题、星星、检查点、黑洞、冰面、迷雾、巡逻块、弹射带、传送门、崩塌地板、闸门、音效和通关记录。

存档使用独立的 `rotate_maze_` 前缀。地图按对角线适配屏幕，任意旋转角度均完整显示。

默认解锁全部 50 关，可直接选择任意关卡；已有成绩记录保留。

## 实现与检查

地图及其机关围绕几何中心旋转。物理沿用原版地图坐标与碰撞系统，把固定屏幕重力 `(0, 17)` 转换为地图坐标 `(17 sin θ, 17 cos θ)`。采用街机式随板运动，不额外模拟离心力和科里奥利力，保留原版滚动手感。

```text
node tools/verify-maps.js
python tools/verify-browser.py
```

前者检查 50 关地图的静态可达性与机关配置；后者需要 Windows Edge、Python 和 websocket-client，检查输入释放、暂停、重力投影、全部关卡渲染及桌面/手机横竖屏尺寸。静态可达性不等同于全部关卡已人工通关。
